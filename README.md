### 🛡️ Engineering & Security Highlights

- **Authentication & Authorization**: Stateless JWT authentication with secure HTTP-only cookies and protected routes.
- **Security Middleware**: Configured `Helmet` HTTP headers, origin-whitelisted `CORS`, and IP-based `express-rate-limit`.
- **Safe File Ingestion**: `Multer` pipeline with file-type MIME enforcement and 5MB payload caps.
- **Data Protection**: Password hashing via `bcrypt` and input sanitation guarding MongoDB queries.
- **Microservice Integration**: Node.js/Express API orchestration coupled with an asynchronous Python/FastAPI analysis service.
- **Containerization & CI/CD**: `Docker` & `Docker Compose` configuration with automated GitHub Actions CI testing workflows.
